## 验证边界

## 已验证

- 从页面新建草稿，从列表操作菜单及只读详情抽屉进入编辑页；独立地址重新打开后回读已保存内容。
- 无修改时禁用保存。真实保存携带 CSRF、完整 9 项可编辑字段及 expectedRevision；以响应更新修订号并留在编辑页，独立 GET 确认持久化。
- 空说明和未设置难度发送 null；空资源分别允许，内存单独填写 64 MiB 可真实保存。非空题面保留首尾空白；标题 Unicode 空白规范化、emoji 码点与重复标签保留。
- 最终 Unicode 回归：标题为 100 个 emoji，边界混合制表符、控制分隔符和 Unicode 空格；标签边界使用同类字符并保留重复项。真实保存及独立 GET 确认规范化结果，同时非空题面首尾空白保持不变。
- 标题 101 个 emoji、6 个标签、CPU 99 ms、内存小数、墙钟小于 CPU、题面 25601 个 emoji 均由页面阻止提交并显示字段错误。
- 在真实 PATCH 前仅注入延迟：连续点击只发一次保存，字段冻结，普通题库链接无法在保存中离开。
- 另发真实竞争保存使修订递增，页面随后保存收到真实 409；保留本地标题并停止提交，不自动重放。
- 错误对象保留 HTTP 状态、业务码、requestId 与原始冲突详情。真实冲突时页面同时展示服务器当前修订号及本地基线修订号，未自动切换基线或覆盖输入。
- 返回题库保留标题筛选、页码与每页条数，列表展示新的服务器内容。
- 真实令牌轮换：先正常保存，再以真实退出与同账号登录轮换服务端会话，页面携带旧缓存令牌保存得到 40301。页面立即 GET 更新 CSRF，保留标题和请求编号，仅在再次手动点击后保存成功；总计恰好 3 次 PATCH（正常保存、拒绝、人工重试），修订号 0→2，无自动重放。
- 真实身份与权限拒绝：本次新建账号的权限变更使旧会话读取返回 401/40100；以普通用户重新登录后，管理详情 GET 与页面 PATCH 均返回 403/40300。编辑页保留输入与请求编号、禁用继续保存、留在原页，不触发登录循环。普通用户直接重新打开编辑地址时，管理员路由守卫返回登录页。
- 九组浏览器错误回归：400/40000、401/40100、403/40300、404/40400、真实 409/40910、500/50000、无效 JSON、不完整成功信封和网络中断。除真实竞争冲突外，其余错误在 HTTP 边界注入；全部保留输入且只发一次 PATCH，400 允许修改后人工重试，其余停止保存。损坏响应和 5xx 显示结果未知，保留可用请求编号；不直接展示注入的服务端原始错误文本。
- 真实保存成功后在浏览器请求边界丢弃响应并抛出网络异常：独立 GET 确认服务端已写入，页面保留输入、停止重放且不误报成功。结果回读确认交互仍属 #26。
- 无效题目编号的真实详情请求失败后，页面显示返回与重读入口，不展示可保存的空白表单。该次请求超时，未取得 HTTP 404 响应，不能据此宣称真实 404 文案已验证。
- 正常退出后真实网关拒绝匿名读取（401），直接打开编辑地址由路由守卫返回管理员登录页。
- 最终类型检查、生产构建、受影响文件的 ESLint、Oxlint、Prettier 和 Git 空白检查通过。前端没有现成的完整测试套件可运行。
