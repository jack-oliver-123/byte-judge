# 受保护业务服务显式复用共享会话适配

规格 002 的题目管理接口需要与用户服务共享浏览器会话，并在每次受保护请求中核验当前身份。沿用架构 04 §4.1，允许已启用受保护接口的业务服务显式依赖 `common-web` 并导入 Session / Web 协议适配；题目服务是首个使用方，公共模块仍不承载业务规则，扫描范围保持各服务自身根包。

共享会话只提供身份快照：题目服务使用独立的 `problem` 内部凭据，通过 HTTP Service Client 和 LoadBalancer 调用用户服务核验当前账户、角色、authEpoch 与撤销事实；依赖不可用时拒绝请求，不使用正向缓存。与单独拆分窄会话模块相比，复用现有适配减少重复契约和装配；代价是业务服务显式承担 Redis 会话依赖及逐请求核验开销。远程核验与共享会话同时使用，不能将二者视为替代方案；按 04 §3.3，题目服务不读取用户库，也不共享账户 Mapper 或数据库账号。
